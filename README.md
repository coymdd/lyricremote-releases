# Lyric Remote

iPhone과 iPad에서 가사와 번역을 함께 보는 음악 리모컨입니다.

## SideStore에 추가

SideStore의 Sources에서 다음 주소를 추가하세요.

```text
https://coymdd.github.io/lyricremote-releases/source.json
```

[SideStore에서 소스 추가](sidestore://source?url=https%3A%2F%2Fcoymdd.github.io%2Flyricremote-releases%2Fsource.json)

GitHub Pages 주소에 일시적인 문제가 있으면 다음 주소도 사용할 수 있습니다.

```text
https://raw.githubusercontent.com/coymdd/lyricremote-releases/main/source.json
```

## 설치 파일

[Releases](https://github.com/coymdd/lyricremote-releases/releases)에서 IPA를 받을 수 있습니다.
SideStore에서 본인의 Apple 계정으로 서명해 설치합니다. 번역 모델은 앱에서 별도로 받습니다.
SideStore와 Apple 계정에 적용되는 설치·서명 갱신 조건은 그대로 적용됩니다.

이 저장소는 앱 설치 파일과 배포 정보만 제공합니다. 앱 개발 소스와 개인 인증 정보는 포함하지 않습니다.
